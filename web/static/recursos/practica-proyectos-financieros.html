02 / DCF Y CRECIMIENTO IMPLÍCITO

¿Qué crecimiento supone esta valoración?

Modelo sencillo de cinco años: flujo libre para la empresa (FCFF), crecimiento anual constante y valor terminal perpetuo. Todos los flujos y el valor empresarial (EV) deben usar la misma moneda y escala. El EV no es el precio de una acción; aquí no se modelan deuda, caja ni acciones.

Introduce tus supuestos o carga el ejemplo sintético.
Reverse DCF: busca por bisección el crecimiento anual de los cinco años entre −90% y +200%. Sólo resuelve si los extremos encierran el objetivo. Bajo estas hipótesis y flujos positivos, el EV aumenta monótonamente con ese crecimiento. Este intervalo y este modelo pueden ser inadecuados para una empresa real.
Ver las ecuaciones

FCFFₜ = FCFF₀ × (1 + crecimiento)ᵗ.
EV = Σₜ₌₁⁵ FCFFₜ / (1 + WACC)ᵗ + [FCFF₅ × (1 + crecimiento terminal) / (WACC − crecimiento terminal)] / (1 + WACC)⁵.

La tasa de descuento debe ser mayor que el crecimiento terminal. El modelo no estima WACC, impuestos, reinversión ni retorno sobre el capital; son supuestos del ejercicio.

03 / VARIACIÓN DE LOS PRECIOS

Mide la variación, sin confundirla con una señal.

Pega cierres positivos en orden cronológico, separados por espacios, punto y coma o saltos de línea. Usa punto para decimales y no uses separadores de miles. Un cierre por sesión; la anualización supone intervalos homogéneos.

Se requieren al menos tres cierres para obtener dos retornos.
Log-retorno: ln(cierreₜ / cierreₜ₋₁). Desviación muestral: resta la media y divide la suma de cuadrados entre n−1. Volatilidad anualizada: desviación × √sesiones. EWMA supone media cero: v₁ = retorno₁²; vₜ = λvₜ₋₁ + (1−λ)retornoₜ²; muestra el último estado × √sesiones. No es el mismo estimador que la desviación muestral.

Más volatilidad significa mayor dispersión, no una dirección de compra o venta. Un resultado de cero puede aparecer con precios constantes; precios con un crecimiento exactamente constante tienen desviación muestral de retornos cercana a cero, aunque su EWMA de media cero sea positiva. No se estima alfa ni se pronostica rentabilidad.
